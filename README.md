**PixelProject** is a small 2D game with its own custom engine in C++ 

The goal of the game is simple: you are playing as a wizard who's main objective is to defend four trees located on the map.
Game includes two enemy types: ones that attack player and others that attack trees.
Player has 4 different skills to be used, each with its own cooldown time and ability: Damage, Great Damage, Healing (can be applied to trees and player) and Teleporting
Game also has game saving mechanics, if you'd like to save your progress on the level: Quick save and Menu Save are supported.
Also the game includes different difficulty levels for all kind of players out there :)

Built with SFML, the project implements a game loop, event management system, UI state navigation, real-time input processing, and interactive gameplay logic
